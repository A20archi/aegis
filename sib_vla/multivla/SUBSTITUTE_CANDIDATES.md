# Substitute "Tiny" VLA — Candidate Comparison Brief

> Purpose: pick a replacement for **TinyVLA** (dropped — ships no trained policy checkpoint) as the second/third "tiny" VLA in our generalization study, alongside **SmolVLA** (main) and the in-progress **NanoVLA** re-implementation. We need a model that is genuinely small, ships **both code AND a downloadable trained policy checkpoint**, ideally is **evaluated on LIBERO** (our stack = LeRobot + LIBERO sim), and cleanly exposes our two plug-in attachment points:
> - **IB "front"** = the visual connector/projector mapping vision-encoder features into the backbone token space.
> - **SIB "back"** = the action head that emits an action chunk `[H × action_dim]`. The head *type* dictates how cleanly SIB attaches: **deterministic regression / flow-matching = clean one-shot; diffusion = must hook denoised x0; AR / VQ action tokens = hardest.**
>
> Compiled 2026-06-13 from primary sources (repos, HF model cards, papers). Claims are cited inline; anything a primary source could not confirm is flagged **[UNVERIFIED]**. **Excluded by instruction: SmolVLA, TinyVLA, NanoVLA.**

## Ranked recommendation

### 🥇 1st — **VLA-Adapter** (`VLA-Adapter/LIBERO-Long` + sibling suite repos)
Best overall fit on all four axes. It is **genuinely tiny** (0.5B Qwen2.5 backbone + ~97M Policy), ships **official code AND non-gated, downloadable LIBERO *policy* checkpoints** for all four suites (plus higher-scoring `*-Pro` variants and a CALVIN one), and posts **state-of-the-art LIBERO SR (97–99% per suite)** that gives us a strong, reproducible baseline. Decisively, its action head is a **deterministic L1-regression chunk (H=8)** — the **cleanest possible SIB attachment** (one-shot action tensor, no denoising/integration loop), matching exactly how SIB sits on SmolVLA; and its **"Bridge Attention" Policy module** is a clean, well-localized IB "front" point (it explicitly injects vision/VLM conditions into the action latents). Same vision stack as our other models (DINOv2 + SigLIP), so the IB front is familiar.

### 🥈 2nd — **MiniVLA** (`Stanford-ILIAD/minivla-vq-libero90-prismatic`)
Strong, well-known Stanford baseline: **~1B**, **official code on the OpenVLA/Prismatic stack**, **non-gated MIT LIBERO checkpoints**, and **native LIBERO** (LIBERO-90 = 82% vs OpenVLA 62%). Same Qwen2.5-0.5B + DINOv2/SigLIP family as VLA-Adapter, so the **IB "front" (Prismatic `mm_projector`) is clean**. The catch is the **SIB "back": MiniVLA emits Residual-VQ discrete action tokens** — the *hardest* SIB case (you'd attach to decoded continuous chunks post-VQ, or work in codeword space), unlike SmolVLA's one-shot head. Note also there is a **non-VQ `minivla-libero90-prismatic`** variant; if you want a cleaner head you'd be giving up the VQ chunking that drives its best numbers.

### 🥉 3rd — **Octo-Small** (`rail-berkeley/octo-small-1.5`)
The **smallest** option by far (**27M**) with **official code + non-gated checkpoint**, and its **diffusion action head** is a *tractable* SIB case (hook the denoised `x0` after the DDPM loop — exactly the pattern we already worked out for TinyVLA). But it loses on two of our hard requirements: it is **JAX/Flax** (largest eval-stack porting cost vs our PyTorch/LeRobot+LIBERO setup), and there is **no official Octo→LIBERO policy checkpoint** — the released weights are OXE-pretrained generalists, and LIBERO numbers come from third-party finetunes, so "reproduce a real LIBERO baseline" would actually require finetuning. Use only if you specifically want the absolute-smallest model and accept the JAX + finetune overhead.

**Not recommended (size/availability):** Pi0/Pi0-FAST (~4B), OpenVLA-OFT/OpenVLA (7B), NORA (3B) all exceed the "tiny < ~1B" bar — though OpenVLA-OFT's L1-regression head and Pi0's flow-matching head are architecturally SIB-friendly if the size bar were relaxed. **Moto / Seer / RoboVLMs** could not be confirmed to release a downloadable *tiny* LIBERO **policy** checkpoint and/or use AR-token heads (hard SIB) — **[UNVERIFIED]**, left out pending a confirmed checkpoint.
